# 🌊 TaskFlow

A modern full-stack task management application designed to help you organize tasks, manage deadlines, and stay productive — with a calm, aesthetic experience.

## ✨ Features

- 🔐 User registration and login
- 🔒 JWT-based authentication
- 📝 Create, edit, complete, and delete tasks
- 📅 Task due dates and ending times
- 🔔 Task deadline notifications
- 📊 Task analytics
- 🗓️ Calendar view
- 🌙 Light and dark theme support
- 🎨 Customizable application experience
- 🌊 Animated beach-themed experience
- 💙 Saudade — quotes focused on love, longing, and deep emotions
- ❤️ Save favorite quotes
- 🔄 Refresh for new quotes and atmospheres
- 📱 Responsive user interface
- ☁️ MongoDB Atlas database
